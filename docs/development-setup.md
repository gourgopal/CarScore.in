# Development Setup

*Pending initialization. This document outlines the intended setup.*

## Prerequisites
- Node.js (Version to be determined upon initialization, ideally LTS)
- Recommended Package Manager: npm, pnpm, or yarn (to be locked upon initialization)
- Git

## Planned Commands
Once the repository is initialized, the standard workflow will be:

- **Install Dependencies**: `npm install` (or equivalent)
- **Start Development Server**: `npm run dev`
- **Type Checking**: `npm run check`
- **Linting & Formatting**: `npm run lint` / `npm run format`
- **Run Unit Tests**: `npm run test`
- **Build for Production**: `npm run build`
- **Preview Production Build**: `npm run preview`

## Editor Configuration
- VS Code is recommended.
- Extensions: Astro, ESLint, Prettier.
